# Governance

## The Blank Slate Principle

This repository starts with no predefined values, conduct rules, or platform ideas. Everything is proposed via pull request. The process itself is the first thing we agree on. If you want something to exist here, submit a PR.

## How a PR Becomes Part of This Repo

1. **Submit** — Open a PR with your proposal.
2. **Discuss** — Discussion period. Anyone can comment.
3. **Approve** — Contributors can approve of PRs.
4. **Merge** — When approval threshold is met, the OP can merge their proposal.

## Approval Thresholds

| PR Type | Approvals Required |
|---------|-------------------|
| Add a value / principle / Conduct | 50% of Contributor approval |
| Amend this governance file | 60% of Contributor approval |
| Typo / formatting fix | 30% of Contributor approval |

Thresholds are amendable via PR (at the governance threshold).

## Who Can Approve

To approve someone else's PR, you must have **submitted at least one valid PR of your own** (open or merged). A "valid PR" is one that:

- Contains a substantive proposal (not spam, not a trivial edit).
- Has been open for at least 24 hours (prevents rapid-fire self-dealing).

Once a user has met these conditions, their membership will be updated to "Contributor" and will therefore have approval rights.

**Why this rule?** It ensures that only people who have engaged with the process can shape its outcomes. It also grows the approver pool organically as people contribute.

## Roles

- **Members** — Anyone in the Discord / with repo access. Can submit PRs, comment, discuss.
- **Contributors** — Participants who have submitted at least one valid PR. Can approve others' PRs.
- **Maintainers** — Senior Contributors who can promote Members to Contributors once a valid PR is proposed
